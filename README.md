## what i've shipped

discord-native, always-on claude code agent. lives in the background, runs my life.

the agentic context layer for nonprofits. one chat over 11+ SaaS tools (donors, grants, finance, programs, comms), every answer cited back to its source record.

**[ione](https://github.com/MatthewKim323/ione)** · winner @ CPP
ai math tutor in the margin. screen-aware, OCR to reasoning to intervention, ElevenLabs voice, supabase knowledge graph grounded in the learner's own files.

**[iris](https://github.com/stephenhungg/iris)** · 2nd place
